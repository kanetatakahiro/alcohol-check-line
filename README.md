# アルコールチェックLINE自動通知システム

当日の対象者とアルコールチェック記録を照合し、
未実施者本人へLINEで通知するシステム。

## 現在の状態
架空データで勤怠とチェック記録を照合する確認用プログラムを作成済み。
TOT・Google Sheets・LINEの本番接続と自動通知は未実施です。

## 確認用プログラム
Node.js 22以降で `npm test` と `npm run demo` を実行できます。
追加パッケージのインストールは不要です。
デモは `examples/fake-data.json` の架空データだけを使用します。
シートの書き換えやLINEへの送信は行いません。

実際の出勤打刻、勤務予定、休暇情報は別々に取り込みます。
打刻なしを公休・有給と推測せず、打刻と全日休暇が食い違う人は要確認とします。
実データをこのデモ用ファイルに入れないでください。

## 開発方針
- GitHubで仕様書とコードを管理する
- Macで開発・テストする
- Node.jsでLINE WebhookとGoogle Sheets連携を実装する
- 通知対象と判定ルールを確認してから本番運用する

## 管理ファイル
- SPEC.md：仕様書
- TEST_CASES.md：確認するテスト項目
- CHANGELOG.md：変更履歴
- README.md：概要と使い方
