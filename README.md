# アルコールチェックLINE自動通知システム

当日の対象者とアルコールチェック記録を照合し、
未実施者本人へLINEで通知するシステム。

## 現在の状態
初期準備中。自動通知はまだ稼働していません。

## 開発方針
- GitHubで仕様書とコードを管理する
- Macで開発・テストする
- Node.jsでLINE WebhookとGoogle Sheets連携を実装する
- 通知対象と判定ルールを確認してから本番運用する

## 管理ファイル
- SPEC.md：仕様書
- TEST_CASES.md：確認するテスト項目
- CHANGELOG.md：変更履歴
- README.md：概要と使い方

## 情報の管理
アクセストークン、パスワード、従業員の個人情報はGitHubに登録しない。
