# 暫定版（Apps Script）の設定手順

TOT連携・本人通知の前に、管理者1人へ未実施者一覧をLINEで送る暫定版です。
シートは読み取りのみで、書き込みはしません。

## 1. LINE側（LINE Developers）
1. Messaging APIチャネルを開き、「チャネルアクセストークン（長期）」を発行する。
2. 「チャネル基本設定」の「あなたのユーザーID」（Uから始まる）を控える。
3. 管理者のLINEで、その公式アカウントを友だち追加する（未追加だと届かない）。

## 2. Apps Script
1. シートの「拡張機能 → Apps Script」を開く。
2. 既存ファイルは変更せず、「＋ → スクリプト」で `AlcoholCheck` を追加し、
   `gas/AlcoholCheck.gs` の内容を貼り付けて保存する。
3. 「プロジェクトの設定 → スクリプト プロパティ」に次を追加する。
   - `LINE_CHANNEL_ACCESS_TOKEN`：1-1のトークン
   - `LINE_ADMIN_USER_ID`：1-2のユーザーID
   - `DRY_RUN`：最初は `true`
4. `alcoholCheckPreview` を実行し、初回の権限承認をする。
   実行ログに当日の対象人数・未実施者が出るので、シートと見比べる。
5. `alcoholCheckSendTestMessage` を実行し、管理者のLINEに届くことを確認する。
6. `alcoholCheckSetupTriggers` を実行する（毎日9時台に出勤前、19時台に退勤前を確認）。
7. 内容に問題がなければ `DRY_RUN` を `false` に変える。ここから実際に送信される。

## 判定の内容（暫定）
- 対象：シート「2026-2028」のシフト行で、当日が「出勤」の人
- 実施済み：「フォームの回答 1」に当日（日本時間）・同じ区分の回答がある人
- 氏名で照合（空白の違いのみ同一視）。同名がいると中止する。
- 測定結果の値は判定に使わない。
- 当日の日付列がない等の不備は、一覧を送らず「確認できませんでした」と送る。
- 全員実施済みの日は送らない。同じ日・同じ区分は1回だけ送る。
