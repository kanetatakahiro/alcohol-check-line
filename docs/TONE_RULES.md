# REBIRTHサポートの口調のルール（正式）

- 決定：2026-11-11・安藤
- 対象：従業員に届くLINEの文面（定型通知・夜の勤怠のお知らせ・問い合わせの返信・FAQの回答文など）

## ルール

1. **労いや気遣いの言葉は残す**
   - 例：「遅くまでお疲れ様でした。」「無理をせず、体調にはお気をつけください。」「本日も一日お疲れ様でした。」
2. **「〜くださいね」は使わない**
   - 対等で自然な敬語に整える。目指すのは「親切な管理本部の担当者」
3. **幼く感じる表現・過度にフレンドリーな表現は避ける**
   - 冒頭のあいさつと、適度な絵文字は使ってよい
4. **変えないもの**
   - 業務ルール・送る対象・送る条件・タイミング・重複防止・分類・引継ぎ条件・既存の機能
   - 必要な注意事項は消さない

## 文面を直すときの進め方

- 文面だけを直し、ロジック（対象・条件・件数・まとめ方・重複防止・お知らせ設定の判定）は変えない。差分で確かめる
- 変更前・変更後は docs/TONE_REVIEW.md に表でまとめる
- 一覧（番号・使用中か未使用か）は docs/MESSAGES_INVENTORY.md
