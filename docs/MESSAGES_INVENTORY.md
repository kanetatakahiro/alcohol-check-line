## 書き方の決まり

- **{care}・{date}・{hours}・{n}・{code}・{月}・{期限} など**：テンプレートの差し込みです。原文のまま残しています。
- **コードの中で文を組み立てている通知**（テンプレートを使わないもの）は、差し込まれる値を `{…}` で示しました（例：`{今日の日付}`）。`{…}` の中の言葉はこの資料で付けた説明で、本文には出ません。それ以外の文字は原文のままです。
- **日替わり（「||」区切り）**：候補が2つ以上ある気遣いの一文は、「LINE文面」シートの参考欄（D列）と同じく「||」で区切ったまま載せています。どの候補を使うかは、日付の数字（例：20261111）を候補の数で割った余りで決まります（AC_pick）。
- **使用中／未使用**：
  - **使用中**：今の本番の設定で、実際に送られる文
  - **未使用**：今は送られない文。コードから呼ばれないものだけでなく、「設定が記録だけのため送られない」「届く経路が無い」ものも含みます。理由は文ごとに書きました。

## 2. 気遣いの一文（「LINE文面」シートの種類「気遣いの一文」・21種類）

すべて E-01（朝の案内）の `{care}` に入ります。朝 8:30 の案内のときだけ使い、ほかの通知では使いません（AC_careLine）。管理場所はすべて gas/AlcoholCheck.gs の AC_CARE（LINE文面のキーは各見出しのとおり）です。

選び方（AC_careKey）：気象庁の発表（さいたま市の警報・注意報、埼玉県南部の天気、さいたまの気温）を朝1回取り、次の順で最初に当てはまるものを使います。警報・注意報 → 雷 → 激しい雨 → 暴風 → 強風 → 雪 → 凍結 → 雨 → 最高気温35℃以上 → 暑い（30℃以上） → 寒い → 寒暖差 → にわか雨 → 晴れ → くもり → どれでもない・天気が取れない（normal）。警報・注意報は、危険度の高いものの種類（雨・風・雪・雷・霧・低温）で選びます。

`{alert}` には、発表中の警報・注意報の名前が、危険度の高い順に最大3つ「・」でつないで入ります（例：レベル３大雨警報・雷注意報）。入りうる名前（AC_WARNING_CODES）：レベル５大雨特別警報／暴風特別警報／暴風雪特別警報／大雪特別警報／レベル３大雨警報／暴風警報／暴風雪警報／大雪警報／レベル２大雨注意報／強風注意報／大雪注意報／風雪注意報／着雪注意報／雷注意報／濃霧注意報／低温注意報／霜注意報／着氷注意報／大雨に関する警報／大雨に関する注意報（名前を公式資料で確認できていない新しい種類のときの表示）。

## 7. 友だち追加・社員番号の登録のときの返信

E-13〜E-16 に載せました（すべて使用中）。登録のときは、管理者へ「確認のお願い」（A-31）も送られます（E-15 のときは送られません）。

## 8. 従業員へのエラー時の返信

従業員へ送るエラーの文はありません。次のときも、従業員には何も届きません（管理者へエラーが届くものは A-32・A-42）。
