## LINE・Webhook・Workers の設定について
- LINE の設定（Webhook URL・応答メッセージ・チャット）は**変更しません**。
- 「応答メッセージ」が有効になっています（10/27 の記録）。従業員が文字を送ると、LINEの自動の応答が返っている可能性があります。問い合わせの仕組みは登録済みの人へ返信しないので、二重にはなりません。未登録の人への案内（1回だけ）と、自動の応答が重なることはあります。段階Fの前に、LINE公式アカウントの管理画面で応答メッセージの内容を見てください（見るだけ）。
- Cloudflare Workers に切り替えていても、いなくても、同じ手順です（問い合わせは既存の転送先で処理するため）。Workers の再送による二重の受信は、受信記録で防ぎます。
