# アルコールチェックLINE自動通知システム

当日の対象者とアルコールチェック記録を照合し、
未実施者本人へLINEで通知するシステム。

## 現在の状態
架空データで勤怠とチェック記録を照合する確認用プログラムを作成済み。
TOT・Google Sheets・LINEの本番接続と自動通知は未実施です。

## 確認用プログラム
Node.js 22以降で `npm test` と `npm run demo` を実行できます。
追加パッケージのインストールは不要です。
デモは `examples/fake-data.json` の架空データだけを使用します。
シートの書き換えやLINEへの送信は行いません。

実際の出勤打刻、勤務予定、休暇情報は別々に取り込みます。
打刻なしを公休・有給と推測せず、打刻と全日休暇が食い違う人は要確認とします。
実データをこのデモ用ファイルに入れないでください。

## TOT読み取り接続の準備
公開仕様 https://developer.kingoftime.jp/ に基づく取得クライアントを追加しました。
このTOT契約のトークンでの実接続はまだ未確認です。
従業員、日別打刻、日別スケジュールをGETだけで取得します。
取得結果はメモリ内のみで扱い、確認画面には件数だけを表示します。
公休・有給などの実際の区分対応は、接続確認後に設定します。

日別スケジュールの取得先は公式資料の `/daily-workings/schedules/{日付}` です
（2026-10-07に `/daily-schedules/{日付}` から修正）。

TOTのアクセストークンには「許可IPアドレス」の設定があります。
実行するパソコン・サーバーの外部IPアドレスが許可されていないと取得に失敗します。
定期実行先を決める際は、固定IPを用意できるかが前提条件になります。

`.env.example` を `.env` にコピーし、`TOT_ACCESS_TOKEN=` の右側へトークンを保存します。
`.env` はGit管理対象外です。トークンをチャットに貼らないでください。
`npm run tot:check -- 2026-10-07` で指定日の読み取りを確認できます。
日付を省略すると日本時間の当日になります。
8:30〜10:00、17:30〜18:30（日本時間）は取得を中止します。
リクエストは直列で1秒間隔、タイムアウトは15秒、転送は拒否します。
取得失敗・応答不備・日付不一致では全体の結果を返しません。
Google Sheets更新やLINE通知にはまだ接続していません。
