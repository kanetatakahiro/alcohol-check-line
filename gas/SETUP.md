# Apps Script の設定手順

シフト表の「出勤」とフォーム回答を照合し、未実施者本人（公式LINEと1対1）と管理者へ通知します。
管理シート（アルコールチェック管理シート）は読み取りのみで、書き込みはしません。
従業員の情報は、別ファイルの「従業員マスタ」で社員番号をキーに管理します（他業務の自動化でも共通で使う）。

## 1. LINE側（LINE Developers / 公式アカウント「REBIRTH 管理本部」）
1. Messaging APIチャネルの「チャネルアクセストークン（長期）」を発行する。
2. 「チャネル基本設定」の「あなたのユーザーID」（Uから始まる）を控える（管理者宛ての通知先）。
3. 管理者のLINEで公式アカウントを友だち追加する（未追加だと届かない）。
4. Webhook URL を、このプロジェクトのWebアプリURLに差し替える（手順2-8）。

## 2. Apps Script
1. 会社アカウント mayu.ando@rebros.info（シート編集者）で、独立プロジェクト
   「アルコールチェック通知（暫定版）」を使う（2026-10-08作成）。
   ※既存の「アルコールチェックLINE自動通知」（Webhook用）は個人Gmailの所有のため使わない。
   アカウントが食い違うと権限承認が通らない。
2. `gas/AlcoholCheck.gs` の内容をコード.gsに貼り付けて保存する。
3. 「プロジェクトの設定 → スクリプト プロパティ」に次を設定する。
   - `LINE_CHANNEL_ACCESS_TOKEN`：1-1のトークン
   - `LINE_ADMIN_USER_ID`：1-2のユーザーID
   - `DRY_RUN`：最初は `true`（送信しない）
   - `NOTIFY_EMPLOYEES`：本人通知を始めるときに `true`（未設定なら管理者一覧のみ）
4. `alcoholCheckPreview` を実行し、権限承認をする。実行ログで対象人数・未実施者を確認する。
5. `alcoholCheckSendTestMessage` で管理者のLINEに届くことを確認する。
6. `alcoholCheckSetupMaster` を実行し、従業員マスタを作成する。
   シフト表の氏名が入るので、管理者が社員番号・所属を入力する。
7. `alcoholCheckSetupTriggers` を実行する（毎日 8:30 朝の案内／10:00 出勤前の入力確認／18:30 退勤前の案内／20:00 退勤前の入力確認と感謝／10分ごとの飲酒検知の確認）。
8. 「デプロイ → 新しいデプロイ → ウェブアプリ」（実行：自分、アクセス：全員）で公開し、
   URLを LINE Developers の Webhook URL に設定する。
9. 従業員が公式LINEを友だち追加し、社員番号だけを送る → マスタの該当行にLINE IDが入る。
   管理者が本人であることを確認し「LINE確認済み」にチェックする。
10. 確認できたら `DRY_RUN` を `false`、`NOTIFY_EMPLOYEES` を `true` にする。

## 従業員マスタの列
社員番号／氏名／別表記（シフト表の書き方が違う場合）／在籍状況（在籍・休職・退職）／所属・拠点／
LINEユーザーID／LINE表示名／LINE登録日時／LINE確認済み／アルコールチェック対象／備考
- 既に別のLINE IDがある社員番号への登録は上書きせず、「LINE登録の要確認」シートに残す。
- 本人通知に使うのは「LINE確認済み」「アルコールチェック対象」がチェック済みで、退職でない行だけ。

## 判定の内容
- 対象：シート「2026-2028」のシフト行で、当日が「出勤」の人
- 実施済み：「フォームの回答 1」に当日（日本時間）・同じ区分の回答がある人
- シフト表の氏名と、マスタの氏名・別表記を照合（空白の違いのみ同一視）。同名がいると使わない。
- 測定結果の値は判定に使わない。
- 当日の日付列がない等の不備は、本人には送らず、管理者へ「確認できませんでした」と送る。
- 同じ日・同じ人・同じ区分は1回だけ送る。

## 毎日の通知
| 時刻 | 宛先 | 内容 |
|---|---|---|
| 8:30 | 出勤者全員 | あいさつ＋天気（気象庁・埼玉県南部／さいたまの気温）＋運転前のチェック案内 |
| 10:00 | 出勤前の入力が確認できない人 | 入力のお願い（未実施と決めつけない文面） |
| 18:30 | 出勤者全員 | 退勤前のチェック案内 |
| 20:00 | 退勤前の入力が確認できない人 | 入力のお願い |
| 20:00 | 連続記録が節目（5・10・20・30・40・50日、以降10日ごと）の人 | 感謝のメッセージ |
- 連続記録：シフトが「出勤」の日だけを数え、出勤前・退勤前のどちらかが欠けたら0に戻る（休みの日は飛ばす）。
- Apps Scriptの時刻指定は前後15分程度ずれる。
- 測定結果が0.14mg/L以下と読めない回答は、10分ごとの確認で管理者へ至急の確認依頼（`ALERT_THRESHOLD` で変更可）。
- `REQUIRE_DEVICE=true` のとき、管理シート「アルコールチェッカー在庫」の「機器所持」にチェックがある人だけに本人通知する（機器が届いたらチェックを入れるだけで対象になる）。
- テストモード：`TEST_CODES`（社員番号）と `TEST_UNTIL`（期限）を設定すると、その人宛ての通知を管理者へ送る。
- `alcoholCheckEstimate`：今日の見込み通数、`alcoholCheckUsage`：日ごとの見込み通数（全員登録済みの場合）。

## 費用
LINEの無料プランは月200通。出勤者全員への朝・夕の案内を送ると月700通前後になり、ライト（月5,000円・5,000通）が必要。テスト中の見込み通数を見て決める。
社員番号の登録への返信は応答メッセージのため通数に含まれない。Apps Scriptは無料。
