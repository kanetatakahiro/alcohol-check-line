## 手順

### 1. コードの反映（安藤さん・Apps Script の画面）

1. Apps Script「勤怠・アルコールチェック管理」を開きます。
2. 「コード.gs」の中身をすべて消し、GitHub の feature/leave-request の gas/AlcoholCheck.gs の中身を貼り付けて保存します。
3. 「ファイル」の「＋」→「スクリプト」で、名前を `LeaveRequest` にして新しいファイルを作ります。gas/LeaveRequest.gs の中身を貼り付けて保存します。
4. 関数 `alcoholCheckShowSettings` を実行し、実行ログの1行目が「コードの版：2026-11-09a」になっていることを確かめます。
5. 2つのファイルの中身を Claude に渡していただければ、指紋（上の表）と合っているかを Claude が照合します。

この時点では `LEAVE_REQUEST_NOTIFY` が未設定なので、何も送らず、何も書きません。

**既存の機能への影響**：

- 時刻指定の処理（アルコールチェックの案内・夜の勤怠の通知・1時間ごとの処理など）は、保存した新しいコードで動きます。ただし、変わったのは上の表の4点だけで、動きは変わりません。
- 「LINE文面」シートに、新しい行 `leaveRequest` が自動で1行足されます（文面の欄は空欄＝既定の文面。次に通知が動いたときに足されます）。
- 受信処理（LINEの受け口・ToTの取り込み）は公開済みの版で動くため、変わりません。

### 2. トリガーの登録（安藤さん）

1. 関数 `alcoholCheckSetupLeaveRequestTrigger` を実行します（初回は権限の確認が出ることがあります）。
2. 左の「トリガー」画面で、`alcoholCheckLeaveRequestNotice`（月ベースのタイマー・毎月10日・午後0時〜1時）が1つだけあることを確かめます。
   - Apps Script の時刻指定は分までは決められないため、12:00から十数分ずれることがあります。
3. `alcoholCheckShowSettings` を実行し、「定期実行」に `alcoholCheckLeaveRequestNotice（時間主導）` が「※このコードの関数ではありません」の注意なしで出ることを確かめます。

既存のトリガー（7件）は消しません。`alcoholCheckSetupLeaveRequestTrigger` は、このトリガーだけを消して作り直します。

### 3. 記録だけで始める：`LEAVE_REQUEST_NOTIFY=record`（安藤さん）

1. 「プロジェクトの設定」→「スクリプト プロパティ」で、次の2つを足します。
   - `LEAVE_REQUEST_NOTIFY` ＝ `record`
   - `LEAVE_REQUEST_EXCLUDE_CODES` ＝ 送らない人の社員番号を「、」区切りで（出勤予定のない人。例：10033、20074）
2. 関数 `alcoholCheckLeaveRequestPreview` を実行します。送らず・書かずに、「送る人」「除く人」の人数と本文が実行ログに出ます（氏名・社員番号は出ません）。
   - 送る人は約50人の見込みです。大きく違うときは止めて Claude に知らせてください。
3. 10日の12時台にトリガーが動くと、従業員マスタのファイルに「希望休案内」シートができ、対象者ごとに「記録のみ（送信しない）」の行が書かれます。除いた人は「送らない（お知らせ停止中／除外の社員番号／同じLINEの重複）」の行になります。
   - 管理者の個別LINEへ、件数だけの報告が1通届きます（氏名・社員番号は入りません）。
   - 10日を待たずに確かめたいときは、`alcoholCheckLeaveRequestNotice` を手で実行しても同じ記録ができます（`record` のときはいつでも記録だけ）。
4. Claude が「希望休案内」シートの内容（人数・除いた人・本文）を確認します。

### 4. 送信を始める：`LEAVE_REQUEST_NOTIFY=on`（別に承認をいただいてから）

- `LEAVE_REQUEST_NOTIFY` を `on` に変えます。`DRY_RUN` が `false` のときだけ送ります（今の本人へのお知らせと同じ）。
- `on` は毎月10日だけ送ります。ほかの日に手で実行しても送りません。
- 同じ月に2回動いても、2回目は送っていない人にだけ送ります（送った人は記録が残るため）。
- 送れなかった人がいたときは、管理者への報告に人数が出ます。`alcoholCheckLeaveRequestNotice` をもう一度手で実行すると、送れなかった人にだけ送ります（10日のうちに行ってください）。
- 送信数：約50通/月（ライトプラン 月5,000通の1％ほど）。
